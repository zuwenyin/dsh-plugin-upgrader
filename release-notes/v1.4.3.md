## 1.4.3

**`AGENTS.md` 把不能退化的行为记了下来。** 十一条规则，每条都附代码位置和守护它的测试：
`GH` 链接（行上**和**历史版本上）、就地换版本、manifest journal、重载前的 boot 文档检查、
「latest 不能是降级」规则、镜像缺口报告、安装阶段、写入锁文案、禁止升级自己、
`bundle-in-use`，以及若干更小的约定（路由仅限回环、一次只跑一批、并发上限、enabled 状态、
绝不空白的失败原因、只允许 zh + en 文案）。两个 README 都链到了它，几处已经漂移的说法被
改正：packument 超时是 20 秒（不是 10），升级不再「先删再装」（就地路径从 1.4.1 起就在跑），
安装阶段是四个而不是三个。

**升级日志现在说明它在做什么，而不是看起来像在卸载。** 一次换版本先打
`install <name>@<new>`，管理器在 pnpm 跑起来之前就以 `already-installed` 拒绝它，然后才打
重试——所以读的人看到两条 install 中间什么都没有，读成了「先删再装」。现在拒绝被点名
（`already declared, so a plain install was refused; the bundle stays loaded`），就地那一行
写明 bundle 没有被卸载（`in place: no removal, the bundle stays loaded`），而那条真的会卸载的
回退路径也说清自己是回退（`in-place replacement declined`）。行为没有任何改变：1.2.0 引入的
就地路径仍然是第一选择，真正的卸载只在它主动放弃时才发生。
