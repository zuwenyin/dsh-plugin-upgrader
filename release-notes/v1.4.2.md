## 1.4.2

**GitHub 链接回到了每一行、以及每一个历史版本号上。**

registry 对 `Accept: application/vnd.npm.install-v1+json` 返回的 abbreviated packument 里
**根本没有** `repository` 字段，所以行上不画仓库链接，历史抽屉里也丢了每个版本自己的 GitHub
地址。

现在 registry 读取器会识别「versions 里缺仓库元数据的 abbreviated 文档」，用完整的
`application/json` 形式把那一个包重取一次，把仓库字段（homepage、bugs、repository）合并回
每一个版本条目。真机验证：12 个已安装插件全部解析出 `repoUrl`，历史版本重新带上各自的仓库
链接。
