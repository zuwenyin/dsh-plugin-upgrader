## 1.0.2

**The published tarball no longer ships development leftovers.** It went from
196.5 KB to 50.4 KB by packaging only what the plugin loads at runtime — plus the
sourcemaps, so a stack trace from the field still points at a line in `src/`.

The release path was made trustworthy in the same pass: publishing now runs from a
tag push through the npm CLI, the trusted-publisher requirement is written down next
to the workflow, and a failed token exchange surfaces as itself instead of degrading
into an anonymous publish that the registry silently refuses.
